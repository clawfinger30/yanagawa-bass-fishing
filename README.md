# 柳川釣行ルアー

![Pasted image 20260830093708.png](assets/柳川/Pasted%20image%2020260830093708.png)
## 目的

10月初旬の柳川クリークでブラックバスを狙うためのルアー・リグ・小物の準備リスト。

- 想定水深：おおむね **0.5〜2m**
- 基本方針：**巻物で広く探す → 反応がある場所をワームで詰める**
- 色は固定せず、**ナチュラル系＋チャート/強アピール系**を用意する
- 購入前に可能なら釣具店で実物を確認する
- Amazonリンクは価格・色を固定せず、商品または検索ページへの参照用
- 柳元の好みで選んでるので、別メーカでも問題ない

# 柳川での基本ローテーション

1. **広く探す**
   - 種類：クランクベイト
   - ルアー：**ピーナッツSR**
   - 条件：まず最初に広くサーチ

2. **風・濁り・水門を探す**
   - 種類：スピナーベイト
   - ルアー：**ハイピッチャー3/8oz**
   - 条件：風・濁りがある、水門周辺

3. **巻きで反応しない魚を拾う**
   - 種類：シャッド
   - ルアー：**ソウルシャッド58SP**
   - 条件：クランク・スピナーベイトに反応しない

4. **カバー・ボトムを撃つ**
   - 種類：フリーリグ
   - ルアー：
     - **ドライブビーバー3.5**
     - **クレイジーフラッパー2.8**
     - **ブルフラット3**
   - 条件：水門・杭・護岸・カバー・ボトム

5. **中層のベイト食いを狙う**
   - 種類：シャッドテールワーム
   - ルアー：
     - **イージーシャイナー3**
     - **スイングインパクト3**
   - 条件：中層にベイトがいる

6. **食わせ切る**
   - 種類：ワッキーDS
   - ルアー：**ライブインパクト3**
   - 条件：魚がいそうなのに他で食わない

7. **表層を狙う**
   - 種類：トップウォーター
   - ルアー：**POPX**
   - 条件：朝夕・超シャロー

# フック・シンカー購入リスト

## フック

- マス針 **#4**：ワッキーDS / ノーシンカーワッキー / ネコの基本
- マス針 **#6**：ライブインパクト3インチを小さめに見せたい場合
- マス針 **#2**：少し大きめのワーム、良型狙い
- オフセット **#1**：クレイジーフラッパー2.8 / ブルフラット3
- オフセット **#1/0〜#2/0**：ドライブビーバー3.5 / ブルフラット3
- オフセット **#2/0**：スイングインパクトFAT3.8

## シンカー

- DS：**2.7g**（基本）、1.8g、3.5g
- フリーリグ：**5g**（基本）、3.5g、7g
- ネイル：**1.3g**（基本）、0.9g、1.8g
- ジグヘッド：**1.8〜2.7g**（基本）、1.3g、3.5g
- テキサス：5g、7g

- ワッキー用Oリング
- Oリングツール
- テキサス用シンカーストッパー
- スナップ（クランク・シャッド用。サイズはルアーとのバランスを見て選択）
