# 柳川釣行ルアー

![Pasted image 20260830093708.png](assets/柳川/Pasted%20image%2020260830093708.png)

## 目的

10月初旬の柳川クリークでブラックバスを狙うためのルアー・リグ・小物の準備リスト。

- 想定水深：おおむね **0.5〜2m**
- 基本方針：
  - 約5,000円構成：**強い巻き → 弱い巻き → フィネス → 反応がなければ移動**
  - 約10,000円以上でカバー・ボトム用リグを採用する構成：**強い巻き → 弱い巻き → カバー・ボトム → フィネス → 反応がなければ移動**
  - DAIWA縛りなどカバー・ボトム用リグを採用しない構成では、その工程を省略する
- 他の釣行者が入った後は、巻物だけで粘らずフィネスへ落とす
- 色は固定せず、**ナチュラル系＋チャート/強アピール系**を用意する
- 購入前に可能なら釣具店で実物を確認する
- Amazonリンクは価格・色を固定せず、商品または検索ページへの参照用
- ルアー本体は **O.S.P縛り / DAIWA縛り / KEITECH縛り / 3メーカー混成最強** の4パターンから選び、小物類はメーカーを固定しない

# 柳川での基本戦略

10月初旬は、1か所でルアー交換を繰り返すより、**魚を探しながらランガンすることを優先**する。

1. **強い巻き**
   - 風・濁り・水門・広い水路を速く探す
   - O.S.P / DAIWAはスピナーベイト、チャターなど
   - KEITECH縛りでは **スイングインパクトFAT 3.8＋ウェイテッドフック**を最も強い巻きとして扱う
2. **弱い巻き**
   - 強い巻きで反応しない魚を拾う
   - 小型シャッドテール、クランク、シャッドなど
3. **カバー・ボトム**
   - O.S.P / KEITECH / 混成の約10,000円以上など、カバー・ボトム用リグを採用する構成でフィネス前に通す
   - O.S.Pはドライブビーバー、KEITECHはクレイジーフラッパーのフリーリグを使用
   - DAIWA縛りなどカバー・ボトム用リグを採用しない構成では省略する
4. **フィネス**
   - 魚がいる確信がある場所、先行者が入った水門・杭・護岸で最後の食わせとして使用
   - ワッキー掛けダウンショットを基本にする
5. **反応がなければ移動**
   - ルアーの種類を増やして同じ場所で粘りすぎない

> **KEITECH縛りの注意**：KEITECHはソフトベイト中心なので、O.S.P / DAIWAのスピナーベイトほど強いアピールの巻物はない。ここではFAT 3.8のウェイテッドフックを「KEITECH内での強い巻き」とする。

## 接続・セット方法

### ジグヘッド

- ラインをジグヘッドのアイへ直接結ぶ
- ワームをまっすぐ刺し、フックポイントを背中側から出す
- 中層ただ巻きで、護岸沿い・流れ・ベイトがいる場所を探す

### ワッキー掛けダウンショット

- 標準構成ではスイベル不要
- フックをライン途中に結び、タグエンドをフックアイへ通してフックポイントを上向きにする
- タグエンドへDSシンカーを直接装着する
- フック〜シンカーは**50〜70cm**目安
- ワーム中央付近をマス針で横切るように掛ける
- 水門・杭・護岸・見えバスで最後の食わせとして使用する

### フリーリグ

- 接続順：**ライン → アイ付きフリーリグシンカー → オフセットフック**
- テキサス用バレットシンカーとは区別する
- ワームを曲げずにオフセットフックへセットする
- 浮きゴミ、杭、水門、護岸変化、カバー、ボトムを攻める

### ウェイテッドフック

- ラインをフックアイへ直接結ぶ
- Swing Impact FATを曲げずにセットする
- 中層〜やや深めを広く巻いて探す
