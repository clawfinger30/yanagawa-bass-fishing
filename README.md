# 柳川釣行ルアー

![Pasted image 20260830093708.png](assets/柳川/Pasted%20image%2020260830093708.png)

## 目的

10月初旬の柳川クリークでブラックバスを狙うための、ルアー・リグ・小物・購入構成の正本。

- 想定水深：おおむね **0.5〜2m**
- 柳川向けの第一推奨：**3メーカー混成・約10,000円パターン**
- 約5,000円構成：**強い巻き → 弱い巻き → フィネス → 反応がなければ移動**
- 約10,000円以上でカバー・ボトムを採用する構成：**強い巻き → 弱い巻き → カバー・ボトム → フィネス → 反応がなければ移動**
- DAIWA縛りなどカバー・ボトム用リグを採用しない構成では、その工程を省略する
- 他の釣行者が入った後は、巻物だけで粘らずフィネスへ落とす
- 色は固定せず、**ナチュラル系＋チャート / 強アピール系**を用意する
- Amazonリンクは価格・色を固定せず、商品または検索ページへの参照用

# 柳川での基本戦略

10月初旬は、1か所でルアー交換を繰り返すより、**魚を探しながらランガンすることを優先**する。

1. **強い巻き**
   - 風・濁り・水門・広い水路を速く探す
   - 基本はスピナーベイト。KEITECH縛りではSwing Impact FATを巻物代替にする
2. **弱い巻き**
   - 小型クランク、シャッド、シャッドテールで強い巻きに反応しない魚を拾う
3. **カバー・ボトム**
   - 採用構成のみフリーリグを通す
   - 浮きゴミ、杭、水門、護岸変化、ボトムを狙う
4. **フィネス**
   - 魚がいる確信がある水門・杭・護岸、先行者後で最後の食わせ
   - ワッキー掛けダウンショットを基本にする
5. **反応がなければ移動**
   - 同じ場所でルアー種類を増やしすぎない

## 組み方で注意する点

- **ワッキーDS**：スイベルなしを標準。フック〜シンカーは**50〜70cm**。フックポイントを上向きにする
- **フリーリグ**：**ライン → アイ付きフリーリグシンカー → オフセットフック**。バレットシンカーとは区別する
- **ジグヘッド / ウェイテッド**：ワームを曲げずにまっすぐセットする
- **スナップ**：クランク・シャッドを頻繁に交換する場合のみ使用する
