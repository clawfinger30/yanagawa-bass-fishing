# 柳川釣行ルアー

![Pasted image 20260830093708.png](assets/柳川/Pasted%20image%2020260830093708.png)
## 目的

10月初旬の柳川クリークでブラックバスを狙うためのルアー・リグ・小物の準備リスト。

- 想定水深：おおむね **0.5〜2m**
- 基本方針：**巻物で広く探す → 反応がある場所をワームで詰める**
- 色は固定せず、**ナチュラル系＋チャート/強アピール系**を用意する
- 購入前に可能なら釣具店で実物を確認する
- Amazonリンクは価格・色を固定せず、商品または検索ページへの参照用
- 柳元の好みで選んでるので、別メーカでも問題ない

---
# 柳川での基本ローテーション

1. **広く探す**
   - 種類：クランクベイト
   - ルアー：**ピーナッツSR**
   - 条件：まず最初に広くサーチ

2. **風・濁り・水門を探す**
   - 種類：スピナーベイト
   - ルアー：**ハイピッチャー3/8oz**
   - 条件：風・濁りがある、水門周辺

3. **巻きで反応しない魚を拾う**
   - 種類：シャッド
   - ルアー：**ソウルシャッド58SP**
   - 条件：クランク・スピナーベイトに反応しない

4. **カバー・ボトムを撃つ**
   - 種類：フリーリグ
   - ルアー：
     - **ドライブビーバー3.5**
     - **クレイジーフラッパー2.8**
     - **ブルフラット3**
   - 条件：水門・杭・護岸・カバー・ボトム

5. **中層のベイト食いを狙う**
   - 種類：シャッドテールワーム
   - ルアー：
     - **イージーシャイナー3**
     - **スイングインパクト3**
   - 条件：中層にベイトがいる

6. **食わせ切る**
   - 種類：ワッキーDS
   - ルアー：**ライブインパクト3**
   - 条件：魚がいそうなのに他で食わない

7. **表層を狙う**
   - 種類：トップウォーター
   - ルアー：**POPX**
   - 条件：朝夕・超シャロー

# リグ一覧

## 必要最低限のリグ

### 1. ジグヘッドリグ
- **ワーム**：スイングインパクト3インチ、イージーシャイナー3インチ
- **フック**：小型ジグヘッド
- **ウェイト**：**1.8〜2.7g基本**（1.3〜3.5g）
- **その他**：基本不要
- **ライン**：**フロロ4〜6lb**
- **使い方**：中層ただ巻き。護岸沿い、ベイトがいる場所を広く探す。

### 2. ワッキー掛けダウンショット
- **ワーム**：ライブインパクト3インチ
- **フック**：**マス針 #4基本**（#6・#2予備）
- **シンカー**：**ダウンショットシンカー2.7g基本**（1.8 / 3.5g）
- **その他**：Oリング任意
- **ライン**：**フロロ4〜6lb**
- **使い方**：水門、杭、護岸、見えバス。最後の食わせ。

## それ以外のリグ

### 3. 通常ダウンショット
- **ワーム**：3インチ前後の小型ワーム
- **フック**：マス針 / DSフック **#4前後目安**
- **シンカー**：ダウンショットシンカー **1.8〜3.5g**
- **その他**：基本不要
- **ライン**：フロロ4〜6lb
- **使い方**：ワームをボトムから少し浮かせて一点で食わせる。

### 4. ダウンショット（スイベル使用）
- **ワーム**：ライブインパクト3インチ、小型ワーム
- **フック**：マス針 / DSフック
- **シンカー**：ダウンショットシンカー **1.8〜3.5g**
- **その他**：**ダウンショット用スイベル**
- **ライン**：フロロ4〜6lb
- **使い方**：通常ダウンショットのバリエーション。糸ヨレ軽減や仕掛け交換性を重視する場合。

### 5. ノーシンカーワッキー
- **ワーム**：ライブインパクト3インチ
- **フック**：マス針 **#4〜#6**
- **シンカー**：なし
- **その他**：Oリング推奨
- **ライン**：フロロ4〜6lb
- **使い方**：超シャロー、足元、護岸際、見えバスを自然なフォールで狙う。

### 6. ジグヘッドワッキー
- **ワーム**：ライブインパクト3インチ等
- **フック**：ジグヘッドワッキー用フック
- **ウェイト**：**0.9〜1.8g程度**
- **その他**：基本不要
- **ライン**：フロロ4〜6lb
- **使い方**：ワッキーを少し速く沈めたい場所や、水流がある場所。

### 7. ネコリグ
- **ワーム**：細身ストレートワーム
- **フック**：ネコリグ用フック / マス針 **#2〜#4目安**
- **シンカー**：**ネイルシンカー1.3g基本**（0.9 / 1.8g）
- **その他**：**Oリング推奨**
- **ライン**：フロロ4〜6lb
- **使い方**：ボトムを一点で丁寧に誘う。食い渋り、水門、杭など。

### 8. フリーリグ
- **ワーム**：ドライブビーバー3.5、クレイジーフラッパー2.8、ブルフラット3
- **フック**：オフセット **#1〜#2/0**
- **シンカー**：**アイ付きフリーリグシンカー5g基本**（3.5 / 7g）
- **その他**：基本不要
- **ライン**：**フロロ10〜14lb**
- **使い方**：水門、杭、護岸変化、カバー、ボトム。シンカーを先行させてワームを遅れてフォールさせる。

### 9. テキサスリグ
- **ワーム**：クレイジーフラッパー2.8等
- **フック**：オフセット **#1前後**
- **シンカー**：**バレットシンカー5〜7g**
- **その他**：シンカーストッパー任意
- **ライン**：フロロ10〜14lb
- **使い方**：ゴミ、草、濃いカバー。すり抜け重視。

### 10. ノーシンカー・オフセット
- **ワーム**：ブルフラット3、スイングインパクトFAT系
- **フック**：オフセットフック
- **シンカー**：なし
- **その他**：基本不要
- **ライン**：フロロ10〜14lb
- **使い方**：自重だけで自然にフォール。シャロー、カバー際。

### 11. ウェイテッドフックリグ
- **ワーム**：スイングインパクトFAT3.8
- **フック**：ウェイテッドオフセットフック
- **ウェイト**：**フック一体ウェイト1.8〜3.5g程度**
- **その他**：基本不要
- **ライン**：フロロ10〜14lb
- **使い方**：シャッドテールを中層〜やや深めで巻く。

# フック・シンカー購入リスト

## フック

- マス針 **#4**：ワッキーDS / ノーシンカーワッキー / ネコの基本
- マス針 **#6**：ライブインパクト3インチを小さめに見せたい場合
- マス針 **#2**：少し大きめのワーム、良型狙い
- オフセット **#1**：クレイジーフラッパー2.8 / ブルフラット3
- オフセット **#1/0〜#2/0**：ドライブビーバー3.5 / ブルフラット3
- オフセット **#2/0**：スイングインパクトFAT3.8

## シンカー

- DS：**2.7g**（基本）、1.8g、3.5g
- フリーリグ：**5g**（基本）、3.5g、7g
- ネイル：**1.3g**（基本）、0.9g、1.8g
- ジグヘッド：**1.8〜2.7g**（基本）、1.3g、3.5g
- テキサス：5g、7g

## その他

- ワッキー用Oリング
- Oリングツール
- テキサス用シンカーストッパー
- スナップ（クランク・シャッド用。サイズはルアーとのバランスを見て選択）
